Mybatis JPA
둘 다 자바에서 DB를 다루는 기술
접근 철학이 다르다.

Mybatis
- 우리나라에서 참 좋아하는 SQL 다루는 방법
- SQL 을 개발자가 직접 작성
- SQL 로 나온 결과만 자바 객체로 변환하여 처리

JPA
- SQL 은 스프링부트에서 만들고, 자바 객체만 다룬다.
- 개발자는 Entity 클래스로 DB 테이블 생성
- JPA 에 내장되어 있는 인터페이스 선언만 하면 끝

해외에서는 JPA 대다수 사용
근래 한국 스타트업에서 JPA 사용

공공기관, 금융, 레거시 유지 보수
-MyBatis

빠른 개발 속도가 중요한 스타트업 신규서비스 CRUD 위주 기능
-JPA
