들여쓰기 계층으로 구조 표현
중복되는 spring 같은 접두사를 한 번만 쓰고 묶을 수 있다.
spring:
  datasource:
    url: jdbc:h2:mem:testdb
    driver-class-name: org.h2.Driver
    username: sa
    password:
  h2:
    console:
      enabled: true
      path: /h2-console
  jpa:
    hibernate:
      ddl-auto: create
    show-sql: true
    properties:
      hibernate:
        format_sql: true
  application:
    name: blog-website
